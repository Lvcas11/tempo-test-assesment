# Sticky Notes

A single-page sticky-notes application (take-home assessment), built with **Vite + React 19 +
TypeScript + Tailwind v4**. Per the brief's "React without stock components / avoid ready-made
solutions" constraint, interactions are hand-written — the only runtime dependencies are
`react` and `react-dom`.

> This is the project scaffold. Features (create/move/resize/delete, editing, drawing, colors,
> persistence) land in subsequent tickets.

## Getting started

Requires Node 20+.

```bash
npm install
npm run dev        # start the dev server (http://localhost:5173)
npm run build      # type-check + production build
npm run preview    # preview the production build
npm run typecheck  # tsc --noEmit (strict)
```

## Browser support

Desktop, minimum resolution 1024×768. Latest Chrome, Firefox, and Edge.
